# Bookmarks

## Local developer environment

- [Colima](https://colima.dev/): Container runtime for macOS and Linux
- [Podman Desktop](https://github.com/podman-desktop/podman-desktop): Desktop app for working with containers and Kubernetes
- [Devbox](https://github.com/jetify-com/devbox): Instant, reproducible development environments powered by Nix
- [DevPod](https://github.com/loft-sh/devpod): Open source alternative to hosted cloud dev environments
- [direnv](https://github.com/direnv/direnv): Automatic per-project environment loading for your shell
- [uv](https://github.com/astral-sh/uv): Extremely fast Python package and project manager
- [mise](https://mise.jdx.dev/): Polyglot tool version manager and task runner

## Developer CLIs and utilities

- [Speckit](https://github.com/jmanhype/speckit): Toolkit for specification-driven development workflows
- [Caveman](https://github.com/JuliusBrussee/caveman): Token-efficient Claude Code skill/CLI for concise dev workflows
- [Task](https://github.com/go-task/task): Modern cross-platform task runner for repeatable dev workflows
- [just](https://github.com/casey/just): Handy command runner for project-specific recipes
- [Lazydocker](https://github.com/jesseduffield/lazydocker): Terminal UI for inspecting and managing Docker workloads

## Source control and DevOps platforms

- [GitHub](https://github.com/): Source control, CI/CD, and collaboration platform
- [GitLab](https://gitlab.com/): End-to-end DevSecOps platform
- [JFrog](https://jfrog.com/): Artifact management and software supply chain platform
- [Dagger](https://github.com/dagger/dagger): Programmable automation engine for build, test, and delivery pipelines
- [Earthly](https://github.com/earthly/earthly): Container-native build tool for repeatable local and CI pipelines

## Cloud platforms

- [Azure](https://azure.microsoft.com/): Microsoft cloud platform
- [Google Cloud](https://cloud.google.com/): Google cloud platform

## Package ecosystems

- [Composer](https://getcomposer.org/): Dependency manager for PHP

## API and secrets tooling

- [Bruno](https://github.com/usebruno/bruno): Git-friendly open source API client and testing tool
- [Infisical](https://github.com/Infisical/infisical): Open source platform for secrets, certificates, and access management

## Developer productivity

- [Raycast](https://www.raycast.com/): Productivity launcher and workflow automation for macOS
- [Monologue](https://monologue.to/): Writing and publishing tool for ideas and notes
- [Atuin](https://github.com/atuinsh/atuin): Syncable shell history and smarter command search
- [Starship](https://github.com/starship/starship): Fast, customizable cross-shell prompt
- [Zed](https://github.com/zed-industries/zed): High-performance code editor built for collaboration and speed
