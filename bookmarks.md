# Bookmarks

## Local developer environment

- [Colima](https://colima.dev/): Container runtime for macOS and Linux
- [uv](https://github.com/astral-sh/uv): Extremely fast Python package and project manager
- [mise](https://mise.jdx.dev/): Polyglot tool version manager and task runner

## Developer CLIs and utilities

- [Speckit](https://github.com/jmanhype/speckit): Toolkit for specification-driven development workflows
- [Caveman](https://github.com/JuliusBrussee/caveman): Token-efficient Claude Code skill/CLI for concise dev workflows

## Source control and DevOps platforms

- [GitHub](https://github.com/): Source control, CI/CD, and collaboration platform
- [GitLab](https://gitlab.com/): End-to-end DevSecOps platform
- [JFrog](https://jfrog.com/): Artifact management and software supply chain platform

## Cloud platforms

- [Azure](https://azure.microsoft.com/): Microsoft cloud platform
- [Google Cloud](https://cloud.google.com/): Google cloud platform

## Package ecosystems

- [Composer](https://getcomposer.org/): Dependency manager for PHP

## Developer productivity

- [Raycast](https://www.raycast.com/): Productivity launcher and workflow automation for macOS
- [Monologue](https://monologue.to/): Writing and publishing tool for ideas and notes
